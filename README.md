# Детективная игра — сайт

Игровая панель для командного расследования. Статический сайт, без сервера и платного хостинга.

## Публикация
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Структура
- index.html — интерфейс игры.
- .nojekyll — отключает обработку Jekyll.

Содержимое дела, документы и финальная разгадка будут добавлены после подготовки полного комплекта.
