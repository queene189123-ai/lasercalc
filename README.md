# Последний вечер — интерактивная детективная игра

Статический сайт для настольного расследования на четырёх игроков. Рассчитан на 3–4 часа, без ведущего: ноутбук + распечатанные материалы.

## Запуск
Откройте `index.html` или опубликуйте репозиторий через GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root).

## Возможности
- 8 персонажей с допросами и браузерным озвучиванием реплик;
- каталог улик и отметки изучения;
- архив с последовательными уровнями доступа;
- хронология, план комплекса, блокнот с автосохранением;
- система подсказок;
- печатный комплект через диалог печати браузера.

## Важно
Текущая сборка — рабочая техническая основа и контентный черновик. Финальная логическая реконструкция, все документы и медиа должны быть проверены как единый сценарий до выдачи игрокам.
